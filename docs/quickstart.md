# Quickstart

1. Read `README.md`.
2. Review `rules/autonomy-gates.md`.
3. Start a task with `prompts/audit-only-bootstrap.md`.
4. Capture context in `templates/HANDOFF.md`.
5. Run the relevant review in `reviews/`.
6. Ask for explicit approval before high-risk actions.

Use synthetic examples until your own team has defined privacy and release rules.
