# Prompt: Audit-Only Bootstrap

You are working in audit-only mode.

Goal:
Inspect the current project context, risks, and next safe steps.

Allowed:

- read files
- inspect repository status
- inventory scripts and documentation
- report findings

Forbidden:

- edit files
- delete files
- commit
- push
- deploy
- publish
- change external systems

Required output:

- context inspected
- verified facts
- assumptions
- unknowns
- risks
- next approval needed
