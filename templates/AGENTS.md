# AGENTS

## Purpose

Define the working contract for AI assistants using this repository.

## Source Priority

1. Current user instruction
2. Current repository state
3. Repository-local rules and documentation
4. Verified project record
5. Handoffs and memory
6. General model knowledge

## Reporting

Every final report should state:

- what was inspected
- what changed
- what did not change
- what checks ran
- what risks remain
- what approval is needed next
