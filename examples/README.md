# Examples

This directory contains synthetic examples for learning and testing CoWork-OS workflows.

All examples are neutral and public-safe. They do not describe real projects, private repositories, customer work, personal data, local paths, domains, credentials, or operational systems.

## Included Examples

- `sample-api`: a synthetic repository onboarding scenario.
- `demo-product`: a synthetic agent-session scenario.
- `example-website`: a synthetic review and handoff scenario.
- `research-notes`: a synthetic knowledge-work scenario for verified notes and handoffs.

Use these examples as patterns, not as claims about real systems.
