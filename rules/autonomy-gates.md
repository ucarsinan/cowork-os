# Rule: Autonomy Gates

## Default Allowed

- read
- analyze
- plan
- report

## Task Approval Required

- edit files
- create files
- run commands with side effects

## High-Risk Approval Required

- commit
- push
- deploy
- delete
- publish
- migrate
- change infrastructure
- affect external systems

## Stop Rule

When approval is unclear, stop and request the smallest specific approval.
